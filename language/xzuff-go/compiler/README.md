# Xzuff Go compiler — first RV64 milestone

This directory contains the first concrete compiler implementation milestone in C++20.

## Current supported source subset

The compiler accepts exactly one function in this form:

```xgo
function main() returns i32 {
    return 42;
}
```

It supports a signed decimal integer return value in the RV64 ADDI immediate range (-2048 through 2047). It tokenizes identifiers, integer literals, punctuation and `//` comments, and emits two little-endian RV64 instructions:

1. `addi a0, zero, immediate` — place the return value in the standard integer return register.
2. `jalr zero, ra, 0` — return to the caller.

The output is an 8-byte **raw RV64 code fragment**. It is not an ELF file, not a complete .xexe executable, and cannot yet be launched by Gravity Kernel. This subset does not yet support module/import declarations, variables, arithmetic expressions, strings, conditionals, loops, functions with parameters, type checking or linking.

## Build

From the repository root, with CMake 3.20+ and a C++20 compiler:

```sh
cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build --output-on-failure
```

The `xzuff-go-codegen-self-test` test checks the exact instruction bytes for return values 0 and 42.

## Compile the sample

```sh
./build/xzuff-go language/xzuff-go/tests/return_42.xgo output.rv64.bin
```

On Windows, use the executable path generated by the chosen CMake generator, for example `build/Release/xzuff-go.exe` with a Visual Studio generator.

## What remains before a usable native compiler

- Complete lexer and formal grammar.
- AST and parser for the actual Xzuff Go language.
- Type checker, diagnostics and intermediate representation.
- Expression and control-flow code generation.
- RV64 ABI, calling convention, object/executable format and relocations.
- Linker/startup code and Gravity Kernel loader integration.
- Standard library and runtime.
- Positive/negative tests for each grammar production.
- Run compiler tests in CI and validate output with a RISC-V disassembler or emulator.

Do not describe this milestone as a complete compiler. It is a real but very limited code-generation prototype that emits two real RV64 instructions for a single integer-return function.
